## 🌟 نظرة عامة

يحول **Antigravity Telegram Bridge** تطبيق تيليجرام على هاتفك إلى بيئة تطوير متكاملة وغرفة تحكم ذكية لوكيل الذكاء الاصطناعي Google Antigravity. سواء كنت بعيداً عن مكتبك، في المواصلات، أو ترغب في مراجعة كودك أثناء التنقل؛ يتيح لك البوت متابعة خطوات تفكير الأيجنت لحظة بلحظة، واختيار القرارات بأزرار تفاعلية بنقرة إبهام، والتنقل بين مختلف مستودعاتك البرمجية، وتجربة مواقع الويب التي تبنيها عبر أنفاق مشفرة HTTPS، وفتح Pull Requests على GitHub بنقرة واحدة.

## ✨ المميزات الخارقة (Powerhouse Features)

### 🔘 أزرار تفاعلية ذكية للخيارات (`pick_opt`)
- يكتشف البوت تلقائياً أي خيارات أو أسئلة يطرحها الأيجنت مثل `1) ... 2) ...` أو `A) ... B) ...`.
- يُنشئ **أزراراً تفاعلية مضمنة داخل تيليجرام (Inline Keyboard)** لتختار إجابتك بنقرة إبهام واحدة دون الحاجة للكتابة.
- مثالي لجلسات التخطيط والمناقشة الاستراتيجية مثل `/grill-me` و `/plan` ومراجعات البنية المعمارية واتخاذ القرارات التقنية.
- يفرض سؤالاً واحداً في كل خطوة أثناء وضع الاستجواب لمنع تكدس النصوص وتسهيل الإجابة من الموبايل.

### ⚡ بث حي وتتبع لحظي للخطوات (Live Streaming Monitor)
- شريط متابعة ديناميكي ومحدّث لحظياً ومباشرة من ملف `transcript.jsonl`.
- يعرض عداد الوقت المنقضي (`⏱️ 1m 24s`)، ورقم الخطوة النشطة (`🔄 الخطوة: #14`)، والأداة التي تعمل الآن (`🛠️ Viewing file`, `Running bash command`)، واسم الجلسة الحالية.
- يمنحك رؤية كاملة لما يفعله الأيجنت بدقة دون تجاوز حدود تيليجرام في إرسال الرسائل (Rate Limits).

### 🎯 إكمال تلقائي لأكثر من 100 مهارة في Antigravity
- يكتشف البوت تلقائياً جميع المهارات البرمجية وأوامر السلاش المثبتة في جهازك (من `~/.gemini/config/skills` ومجلد المشروع `.agents/skills` والإضافات plugins).
- يربطها مباشرة بقائمة أوامر تيليجرام الرسمية؛ بمجرد كتابة `/` يظهر لك إكمال تلقائي مذهل لكل المهارات مع شرح وظيفي لكل منها!

### 📂 استوديو إدارة وتغيير المشاريع والتعقب التلقائي لـ IDE
- `/projects`: يفحص مجلد مشاريعك الرئيسي `projects_root` ويعرض قائمة تفاعلية بكل المشاريع لتغيير بيئة العمل الحالية بنقرة واحدة.
- `/cd [path]`: تغيير مسار مجلد العمل يدوياً أو تثبيت مسار محدد.
- `/auto`: مزامنة مسار العمل تلقائياً وبشكل حي مع المشروع المفتوح حالياً في نافذة Antigravity IDE على جهازك.

### 💬 إدارة متقدمة للجلسات المتعددة
- `/chats`: مستعرض تفاعلي للجلسات والمحادثات السابقة مع إمكانية استئناف أي جلسة بضغطة زر.
- `/new`: بدء جلسة جديدة ونظيفة تماماً في أي وقت.
- `/export`: تصدير سجل المحادثة بالكامل أو الملخص بصيغة Markdown أو مستند نصي مباشرة إلى هاتفك.

### 🔄 تبديل الحسابات والتعافي التلقائي (Auto-Failover)
- `/accounts`: التبديل السلس بين حسابات جوجل أو ملفات التوكن المختلفة.
- `auto_failover`: اكتشاف استهلاك الحصة (Quota Limits) أو بطء الاستجابة تلقائياً والتحويل فوراً إلى الحساب الاحتياطي دون انقطاع عملك.

### 🌐 استعراض فوري ومشفر لتطبيقات الويب (Cloudflare Tunnels)
- `/servers`: يكتشف خوادم التطوير المحلية النشطة على جهازك (مثل Vite `5173`, Next.js `3000`, Flutter Web, Django, FastAPI).
- `/preview [port]`: ينشئ نفقاً مؤقتاً ومشفراً فورياً عبر Cloudflare Tunnel (`*.trycloudflare.com`)، مما يتيح لك فتح واختبار موقعك وتطبيقاتك الحية مباشرة من متصفح هاتفك عبر رابط HTTPS آمن من أي مكان في العالم!

### 🌿 استوديو Git وإنشاء Pull Requests بنقرة واحدة
- `/diff`: استعراض الفروقات البرمجية الملونة بدقة مع إرسال الملفات المعدلة تلقائياً.
- `/git`: فحص حالة الفرع والملفات والتحديثات الأخيرة.
- `/commit [رسالة]`: تثبيت التعديلات وحفظها في Git محلياً.
- `/push`: رفع التعديلات إلى المستودع البعيد على GitHub.
- `/undo`: التراجع عن التعديلات غير المثبتة أو حفظها مؤقتاً (Stash).
- `/pr [عنوان]`: رفع الفرع وفتح Pull Request على GitHub عبر `gh CLI` وإرسال الرابط المباشر.

### 🎙️ الرسائل الصوتية وتبادل ملفات الأكواد في الاتجاهين
- أرسل رسائل صوتية باللغة **العربية أو الإنجليزية**؛ يقوم البوت بتفريغها صوتياً وتمريرها كتعليمات برمجية واضحة للأيجنت.
- ارفع أي ملف برمجي أو مستند (`.py`, `.dart`, `.ts`, `.json`, `.md`) وسيقوم الأيجنت بدمجه وفحصه مباشرة.
- المخرجات المرئية ومخططات واجهات المستخدم والصور التي يولدها الأيجنت تصلك فوراً كصور عالية الدقة على تيليجرام.

### 📸 لقطات شاشة حية لشاشات الكمبيوتر والترمينال
- `/screenshot`: التقاط شاشة الكمبيوتر لايف بدقة عالية على Linux (Wayland `grim` / X11 `scrot`) و macOS و Windows.
- `/sh [أمر]`: تشغيل أوامر الشل والترمينال المباشرة مع بث المخرجات.
- `/stop`: إيقاف فوري وآمن للمهام والعمليات الجارية.

### 🛡️ الأمان والتنظيف الذاتي
- **اقتران أمني أوتوماتيكي:** يُقفل البوت تلقائياً على أول حساب تيليجرام يتواصل معه (`allowed_user_id`) ويمنع أي وصول خارجي غير مصرح به.
- **خدمة تنظيف الوسائط (24h):** معالج يعمل في الخلفية يحذف الصور والملفات المؤقتة القديمة دورياً للحفاظ على مساحة القرص لديك.

## ⚡ التثبيت السريع في دقيقتين

### 1. استنساخ المستودع (Clone)
```bash
git clone https://github.com/coach-nooreldean/antigravity-telegram-bridge.git
cd antigravity-telegram-bridge
```

### 2. تشغيل معالج التثبيت التفاعلي
```bash
chmod +x install.sh
./install.sh
```

سيقوم المعالج التفاعلي بما يلي:
1. التحقق من وجود Python 3.9+ وأداة `agy` CLI.
2. اختيار لغتك المفضلة (**العربية** أو **الإنجليزية**).
3. إدخال توكن البوت من [@BotFather](https://t.me/BotFather).
4. تحديد مسار مجلد مشاريعك العام ومجلد العمل الافتراضي.
5. التحقق من الأدوات التكميلية (`cloudflared` للأنفاق المشفرة، و `ffmpeg` للصوت).
6. إمكانية تثبيت خدمة خلفية دائمة تعمل 24/7 عبر `systemd`.

### 3. ابدأ العمل!
افتح البوت في تيليجرام وأرسل `/start` أو أي تعليمات برمجية بلغتك الطبيعية!

## ⚙️ ملف الإعدادات (`config.json`)

يقوم المعالج بإنشاء هذا الملف تلقائياً، ويمكنك تعديله يدوياً في أي وقت:

```json
{
  "bot_token": "YOUR_TELEGRAM_BOT_TOKEN_FROM_BOTFATHER",
  "allowed_user_id": null,
  "language": "ar",
  "projects_root": "~/projects",
  "workspace_mode": "auto",
  "current_workspace": "~/projects/my-app",
  "current_model": "default",
  "current_effort": "default",
  "auto_failover": true,
  "task_timeout_seconds": 600,
  "sentry_url": "",
  "force_new": false,
  "agy_bin": "agy"
}
```

### شرح الإعدادات
- `bot_token`: توكن البوت الذي حصلت عليه من [@BotFather](https://t.me/BotFather).
- `allowed_user_id`: معرّف تيليجرام الخاص بك. اتركه `null` ليقترن البوت تلقائياً مع أول شخص يرسل `/start`.
- `language`: لغة الواجهة (`"ar"` للعربية، `"en"` للإنجليزية). يمكن تغييرها فوراً عبر أمر `/lang`.
- `projects_root`: المسار الأب الذي يضم كل مجلدات مشاريعك لاستخدامه في أمر `/projects`.
- `workspace_mode`: وضع مسار العمل (`"auto"` لتتبع IDE المفتوح، أو `"manual"` لتثبيت مسار معين).
- `auto_failover`: تفعيل التبديل التلقائي بين حسابات جوجل عند بلوغ حدود الاستخدام.
- `task_timeout_seconds`: أقصى وقت للمهمة بالثواني قبل الإيقاف الاحترازي (افتراضياً: `600`).
- `agy_bin`: مسار أداة `agy` على جهازك.

## 🛠️ التشغيل الدائم 24/7 عبر Systemd (Linux)

لإبقاء البوت يعمل دائماً في الخلفية كخدمة مستخدم:

```bash
# تفعيل وبدء الخدمة
systemctl --user daemon-reload
systemctl --user enable antigravity-bridge.service
systemctl --user start antigravity-bridge.service

# متابعة السجلات الحية (Logs)
journalctl --user -u antigravity-bridge.service -f

# فحص الحالة
systemctl --user status antigravity-bridge.service
```

## 💡 أدوات مساعدة موصى بها (اختيارية)

- **Cloudflare Tunnel (`cloudflared`)**: لتشغيل أمر `/preview` ومعاينة مواقع وتطبيقات الويب (Vite, Next.js, Flutter) عبر الإنترنت برابط HTTPS مجاني وفوري.
  - *أنظمة Ubuntu/Debian:* `sudo apt install cloudflared` أو تحميله من [مستودع Cloudflare](https://github.com/cloudflare/cloudflared/releases).
  - *أنظمة Arch Linux:* `sudo pacman -S cloudflared`
  - *أنظمة macOS:* `brew install cloudflared`
- **FFmpeg (`ffmpeg`)**: للتعامل مع الرسائل الصوتية وتحويلها للأيجنت.
  - *أنظمة Ubuntu/Debian:* `sudo apt install ffmpeg`
  - *أنظمة macOS:* `brew install ffmpeg`
- **GitHub CLI (`gh`)**: لفتح الـ Pull Requests بنقرة واحدة عبر أمر `/pr`.
  - التثبيت من [cli.github.com](https://cli.github.com/).
